# instagram-agent
Agente de Instagram para que me lleve la red social

- `CLAUDE.md`: quién soy, reglas del agente (todo pendiente de aprobación) y datos de Metricool.
- `estrategia.md`: pilares de contenido, ganchos, horarios e interacción.
- `referentes.md`: cuentas de referencia.
- `informes/`: análisis. `planes/`: planes de contenido con guiones.
- Comandos: `/ig-analisis`, `/ig-competencia`, `/ig-plan`, `/ig-reel`, `/ig-nocturno`.
